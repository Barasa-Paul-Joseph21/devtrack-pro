
Frontend (React + Vite)

Design assets
- Place UI reference images (Stitch AI outputs) in `src/assets/ui-reference/`. See `src/assets/ui-reference/README.md` for guidance.

Design stack to implement UI:
- React
- Tailwind CSS
- shadcn/ui
- Framer Motion
- Lucide React icons
- React Three Fiber (Three.js)

Run dev server:

1. npm install
2. npm run dev

Configure `vite` proxy or set full API URLs in `axios` calls to point to the backend (e.g., http://localhost:5000).
